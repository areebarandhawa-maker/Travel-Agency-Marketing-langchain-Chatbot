# Travel Agency Marketing Chatbot

A conversational PDF-based chatbot using Retrieval-Augmented Generation (RAG).

## Technologies
- Python
- Google Colab
- LangChain
- Groq LLM
- HuggingFace Embeddings
- ChromaDB

## Features
- PDF document loading
- Text splitting
- Vector database
- Context-based question answering
- Conversational memory
- Follow-up question understanding

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required PDF.
3. Add your Groq API key in Colab Secrets.
4. Run all cells.
5. Start chatting with the chatbot.
