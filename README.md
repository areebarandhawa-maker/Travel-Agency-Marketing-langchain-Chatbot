# Travel-Agency-Marketing-langchain-Chatbot
PDF-based Travel Agency Marketing Chatbot using LangChain, Groq and RAG.
Travel Agency Marketing Chatbot
Project Overview

This project is a PDF-based conversational chatbot built using Retrieval-Augmented Generation (RAG).

It answers questions using information retrieved from a Travel Agency Marketing Strategy PDF.

Technologies Used
Python
LangChain
Groq LLM
HuggingFace Embeddings
ChromaDB
Google Colab
Features
PDF document loading
Text splitting and embedding
Vector database retrieval
Context-based question answering
Conversational memory
Follow-up question understanding
Installation
bash
pip install -r requirements.txt

API Key

Add your Groq API key securely using Google Colab Secrets.

How to Run
Open the notebook in Google Colab.
Upload the required PDF into the docs folder.
Add your Groq API key.
Run all cells.
Start chatting with the bot.
